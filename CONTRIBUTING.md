# Contributing

## Definition of done

A change is done when all of these are true:

1. Behaviour changes are covered by tests.
2. Documentation matches the behaviour.
3. `make precommit` passes.
4. The bead for the work is closed with a reason that names the commits, and follow-up work is filed as beads.

## Commits and pull requests

- Subject under 72 characters, imperative, sentence case; detail in the body; bead id named.
- A pull request states what changed and why, the commands run, and the documentation updated.
- `CHANGELOG.md` carries release notes only.
