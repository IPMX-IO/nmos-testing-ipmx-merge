# Word list

Words and phrases to remove, with the replacement. The left column is never used. The right column is what to write instead, or "delete" when the sentence loses nothing without it.

## Phrases that read as machine-written

| Do not write | Write instead |
|---|---|
| the hard part, the hardest part, the tricky part, the real challenge | Name the specific difficulty: "sustaining 64 flows without packet loss is where the schedule risk is" |
| hard problem, the hard problems | Name the problem |
| load-bearing | Name what depends on the thing: "three modules call this function" |
| here's the thing | delete |
| it's worth noting, it should be noted | delete; state the note |
| the key insight, the key takeaway | delete; state the fact |
| under the hood | "in the implementation", or name the component |
| heavy lifting | Name the work: "the parsing", "the retry logic" |
| that said, having said that | delete, or "However," |
| the whole point, the point is | delete; state the fact |
| at the end of the day | delete |
| honestly, to be honest, the honest answer is | delete; open with the substance |
| actually, genuinely, simply, really, just (as intensifiers) | delete |
| the ask | "the request", "the question" |
| the story (meaning an argument) | "the argument", "the explanation" |
| the play, the move | "the plan", "the next step" |
| the workup | "the full report", "the analysis" |
| leverage (verb) | "use" |
| utilize | "use" |
| robust, seamless, powerful, elegant, cutting-edge | delete; state the measurable property |

## Figurative verbs

| Do not write | Write instead |
|---|---|
| carries (a packet carries a value) | includes, contains; "the value is in the packet" |
| holds (a struct holds a value) | contains, has |
| lands (a request lands, a change lands) | arrives, is received, is merged, is committed |
| lives in (the config lives in /etc) | is in |
| surfaces (an error surfaces) | is returned, is raised, is logged, is reported |
| drives (a timer drives the loop) | triggers, controls, starts |
| anchors, cements, bolts on | Name the relationship: "is attached to", "is fixed by", "depends on" |
| unpacks (the section unpacks the design) | explains, describes |
| belongs to (figurative ownership) | "is part of", "is in" |
| threading the needle | delete; state the two constraints being met |
| moving the needle | delete; state the measured change |
| wants, expects, cares about (of a module or a function) | requires, accepts, rejects, checks |

## Idiom and casual register

| Do not write | Write instead |
|---|---|
| north of 64 | more than 64 |
| somebody has to define | "X defines", or "this is undefined" |
| start to hurt | "become a concern", "exceed the limit" |
| before the numbers travel | "before the numbers are used outside the team" |
| the ground is firm | "where the design is well supported" |
| low-hanging fruit | "changes that are small and have a known benefit" |
| a no-brainer | delete; state the reason the choice is clear |
| out of the box | "with the default configuration" |
| on the same page | "in agreement" |
| circle back | "return to", "discuss again on <date>" |
| ballpark | "approximately", "an estimate" |
| nail down | "decide", "confirm" |

## Punctuation

| Do not write | Write instead |
|---|---|
| em dash (—) as punctuation | a period and a second sentence; a comma; a colon before a list or an explanation; parentheses for a true aside |
| spaced hyphen ( - ) or en dash ( – ) used as an em dash | same as above |
| § symbol in prose | "section 4", "(report section 4)" |

En dashes in numeric ranges (2026–2027, lines 40–52) are fine.

## Spelling

US spelling throughout: behavior, color, initialize, optimize, license (noun and verb), analyze, center, catalog.
